# Список крупных задач для систем банка "Стандарт"

## 📋 **1. АБС (Автоматизированная банковская система)**

### Депозитные продукты:
- **T1**: Разработка API интеграции для депозитных продуктов
    - Создание REST API для получения списка депозитных продуктов
    - API для создания депозитного счета
    - API для получения ставок и условий
    - Интеграция с основной логикой на PL-SQL

- **T9**: Автоматизация процесса открытия депозитов
    - Исключение ручного участия бэк-офиса
    - Автоматическая проверка данных клиента
    - Автоматическое создание счетов

### Кредитные продукты:
- **T15**: API для предодобренных кредитных предложений
    - Интеграция с системой скоринга
    - Получение лимитов по клиентам
    - API для проверки статуса предодобрения

---

## 🌐 **2. Интернет-банк**

### MVP Депозиты (6 месяцев):
- **T2**: Разработка формы подачи заявки на депозит
    - Интерфейс выбора депозитного продукта
    - Форма ввода параметров депозита
    - Отправка заявки в бэк-офис для ручной обработки

### Финальная версия Депозиты (12 месяцев):
- **T10**: Полная автоматизация открытия депозитов
    - Интеграция с API АБС
    - Автоматическое создание счетов
    - Уведомления об успешном открытии

### Кредитные продукты:
- **T12**: Подача заявки на кредит с предодобрением
    - Отображение предодобренных предложений
    - Быстрая форма подачи заявки
    - Интеграция с кредитным конвейером

---

## 🌍 **3. Сайт**

### Депозитные продукты:
- **T3**: Лендинг с формой заявки на депозит
    - Маркетинговая страница депозитных продуктов
    - Форма для потенциальных клиентов
    - Интеграция с кол-центром

### Кредитные продукты:
- **T13**: Подача кредитной заявки для новых клиентов
    - Форма предварительной заявки
    - Интеграция с БКИ для проверки
    - Передача в кредитный конвейер

---

## 📞 **4. Система кол-центра**

### Депозитные продукты:
- **T4**: Интеграция с АБС для получения актуальных ставок
    - API для получения текущих ставок
    - Автоматическое обновление информации
    - Интерфейс для операторов

- **T5**: Обработка заявок с сайта
    - Автоматическое создание задач для операторов
    - Интерфейс работы с заявками
    - Скрипты для работы с клиентами

### Кредитные продукты:
- **T14**: Обработка кредитных заявок с сайта
    - Принятие заявок от новых клиентов
    - Первичная консультация по телефону
    - Передача в кредитный отдел

## 🤝 **5. Система партнерского кол-центра**

### Депозитные продукты:
- **T6**: SFTP интеграция для обмена файлами
    - Настройка SFTP сервера
    - Автоматическая передача файлов с заявками
    - Получение обратной связи по обработке

### Кредитные продукты:
- **T16**: Расширение SFTP для кредитных заявок
    - Передача кредитных заявок партнерам
    - Получение результатов обработки
    - Интеграция с основными системами

---

## 🔍 **6. Система кредитного скоринга**

    - API для интернет-банка

- **T8**: Скоринг для новых клиентов
    - Интеграция с БКИ
    - Быстрая оценка кредитоспособности

## 🔗 **Ключевые зависимости**

1. **T2 ← T1**: Форма депозитов зависит от API АБС
2. **T4 ← T1**: Кол-центр зависит от API ставок АБС
3. **T5 ← T3**: Обработка заявок зависит от формы на сайте
4. **T10 ← T2**: Автоматизация зависит от MVP формы
5. **T12 ← T7**: Кредитная форма зависит от скоринга
6. **T11 ← T12**: Конвейер зависит от форм подачи заявок
